# GladKit

Расширение-помощник для браузерной игры [Gladiators.ru](https://www.gladiators.ru).

Только удобства: фильтры, метки игроков, статистика, заметки. Никакой
автоматизации, никаких действий от имени игрока, никаких запросов на сервер
игры. Всё хранится локально в браузере.

## 🚀 Установка

**Способ 1. Chrome Web Store (рекомендуется)**

Открой страницу расширения и нажми «Установить»:

**[Установить GladKit](https://chromewebstore.google.com/detail/gladkit/ИД_РАСШИРЕНИЯ)**

*(работает для Chrome, Edge, Яндекс.Браузера, Opera, Vivaldi, Brave)*

**Способ 2. Установка из исходников**

Нужна, если хочешь проверить код перед установкой, или если Chrome Web Store
недоступен. Инструкция — в [INSTALL.md](./INSTALL.md).

## Возможности

- **Фильтр турниров** — на странице арены фильтрует карточки по уровню и типу.
- **Метки игроков** — цветные пометки и заметки на других игроков. Ник подсвечивается везде, где появляется.
- **Статистика коллекции** — в профиле показывает, сколько уникальных турниров ты собрал по каждой из 6 регулярных категорий.
- **Зал трофеев** — панель со статистикой по датам: победы и финалы за каждый день.
- **Скрытие блоков** — в профиле игрока и гильдии можно скрыть блоки наград тумблерами.
- **Свои пункты в меню игры** — добавление своих ссылок в главное меню.
- **Пагинация на арене** — крупнее, перенесена наверх.
- **Менеджер** — отдельная страница со всеми настройками, словарём турниров и метками игроков.

## Чего расширение НЕ делает

- Не отправляет данные на сервер.
- Не совершает действий за игрока.
- Не обращается к серверам игры.
- Не читает личную информацию (пароли, сессии, сообщения).

Расширение запрашивает только доступ к `storage` (для настроек) и к домену
`gladiators.ru` — это видно прямо в `manifest.json`, можно свериться самому.

## Совместимость

Работает в браузерах на движке Chromium:

- Google Chrome
- Microsoft Edge
- Яндекс.Браузер
- Opera
- Vivaldi
- Brave

Firefox пока не поддерживается.
