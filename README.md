# GladKit

Расширение-помощник для браузерной игры [Gladiators.ru](https://www.gladiators.ru).

Только удобства: фильтры, метки игроков, статистика, заметки. Никакой
автоматизации, никаких действий от имени игрока, никаких запросов на сервер
игры. Всё хранится локально в браузере.

## Возможности

- **Фильтр турниров** — на странице арены фильтрует карточки по уровню и типу.
- **Метки игроков** — цветные пометки и заметки на других игроков. Ник
  подсвечивается везде, где появляется.
- **Статистика коллекции** — в профиле показывает, сколько уникальных
  турниров ты собрал по каждой из 6 регулярных категорий.
- **Зал трофеев** — панель со статистикой по датам: победы и финалы за
  каждый день.
- **Скрытие блоков** — в профиле игрока и гильдии можно скрыть блоки
  наград тумблерами.
- **Свои пункты в меню игры** — добавление своих ссылок в главное меню.
- **Пагинация на арене** — крупнее, перенесена наверх.
- **Менеджер** — отдельная страница со всеми настройками, словарём
  турниров и метками игроков.

## Чего расширение НЕ делает

- Не отправляет данные на сервер.
- Не совершает действий за игрока.
- Не обращается к серверам игры.
- Не читает личную информацию (пароли, сессии, сообщения).

## Установка

Смотри [INSTALL.md](INSTALL.md) — подробная инструкция со скриншотами.

Кратко: скачать ZIP, распаковать, загрузить в `chrome://extensions`
в режиме разработчика.

## Обновление

Автообновления нет, потому что расширение не в Chrome Web Store.
Чтобы обновиться:

1. Скачай свежий ZIP с GitHub.
2. Распакуй, замени старую папку.
3. В `chrome://extensions` нажми «Обновить» рядом с расширением.

Настройки и метки сохранятся — они лежат в браузере, а не в папке
расширения.

## Совместимость

Работает в браузерах на движке Chromium:

- Google Chrome
- Microsoft Edge
- Яндекс.Браузер
- Opera
- Vivaldi
- Brave

Firefox пока не поддерживается.
