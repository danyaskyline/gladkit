# Установка GladKit

Расширение устанавливается вручную, в режиме разработчика. Это несложно,
но требует внимательности. Займёт 2–3 минуты.

## Что нужно

- Браузер на движке Chromium: Chrome, Edge, Яндекс.Браузер, Opera, Vivaldi, Brave.
- Скачанный и распакованный архив с расширением.

## Шаг 1. Скачать ZIP

1. Открой <https://github.com/danyaskyline/gladkit>
2. Нажми зелёную кнопку **Code**.
3. В выпадающем меню выбери **Download ZIP**.
4. Скачается файл `gladkit-main.zip`.

<!-- 📸 Скриншот: кнопка Code → Download ZIP -->

## Шаг 2. Распаковать

1. Найди скачанный файл.
2. ПКМ → **Извлечь всё** (Windows) или двойной клик (macOS).
3. Получится папка `gladkit-main`. Внутри неё — файлы расширения:
   `manifest.json`, папки `config/`, `core/`, `content/` и т. д.

**Важно:** не заходи внутрь папки и не выбирай вложенные папки при
установке. Нужна именно папка, где лежит `manifest.json`.

## Шаг 3. Открыть страницу расширений

В адресной строке набери:

- Chrome, Edge, Яндекс, Opera, Vivaldi, Brave: `chrome://extensions`

Если не сработало, попробуй `edge://extensions` (для Edge) или
`browser://extensions` (для Яндекс.Браузера).

## Шаг 4. Включить режим разработчика

В правом верхнем углу страницы расширений найди тумблер **«Режим
разработчика»** (Developer mode). Включи его.

После включения появятся три кнопки: **«Загрузить распакованное
расширение»**, **«Упаковать расширение»**, **«Обновить»**.

<!-- 📸 Скриншот: тумблер Developer mode в правом верхнем углу -->

## Шаг 5. Загрузить расширение

1. Нажми **«Загрузить распакованное расширение»** (Load unpacked).
2. В диалоге выбери папку `gladkit-main` — ту самую, где лежит
   `manifest.json`.
3. Нажми **«Выбрать папку»**.

Расширение появится в списке. Рядом с иконкой браузера (в тулбаре)
появится иконка GladKit.

<!-- 📸 Скриншот: GladKit в списке расширений + иконка в тулбаре -->

## Шаг 6. Проверка

1. Открой <https://www.gladiators.ru>
2. Иконка GladKit в тулбаре — активна.
3. Клик по иконке — откроется попап с кнопкой «Открыть менеджер».

Если что-то не появилось — открой `chrome://extensions`, найди GladKit
и посмотри, нет ли ошибок. Ошибки обычно написаны по-английски, но
я могу помочь разобраться.

## Обновление вручную

Когда выйдет новая версия:

1. Скачай свежий ZIP с GitHub.
2. Распакуй в новую папку или замени старую.
3. В `chrome://extensions` нажми **«Обновить»** (круговая стрелка)
   рядом с GladKit.

Настройки, метки игроков и словарь сохранятся — они лежат в браузере,
а не в папке расширения.

## Возможные проблемы

### «Manifest file is missing or unreadable»

Выбрал не ту папку. Нужна папка, в которой лежит `manifest.json`,
а не вложенная в неё.

### Расширение не появляется в списке

Проверь, что режим разработчика включён. Без него кнопки «Загрузить
распакованное» не будет.

### «Режим разработчика» отключился сам

Некоторые корпоративные политики или антивирусы отключают его.
Проверь настройки браузера или обратись к администратору, если это
рабочий компьютер.

### Chrome отключил расширение после обновления браузера

Иногда бывает. Зайди в `chrome://extensions`, найди GladKit и включи
его тумблером.
